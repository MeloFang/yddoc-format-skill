# 校对与文字优化规则

> 分工：`wording-rules.md` 管**用词口径**（禁用词、称谓、引用格式）；本文件管**错误与表达**（错别字、病句、冗余、句式）。
> 触发时机：**每次交付前必跑一遍**，无论用户是否明确提出。公文、汇报材料、发言稿一律适用。

## 一、必查的错别字与易混词（逐对核对）

### 形近 / 音近致错

| 正确 | 误写 |
| --- | --- |
| 部署 | 布署 |
| 截至（到某时为止） | 截止（到某时停止） |
| 账号、账户 | 帐号、帐户 |
| 登录（进入系统） | 登陆（上岸） |
| 制定（定出） | 制订（创制） |
| 度过（时间） | 渡过（水域、难关） |
| 反映（情况上报） | 反应（回应、化学） |
| 启用（开始使用） | 起用（重新任用） |
| 权力（职权） | 权利（权益） |
| 检查（查看） | 检察（司法） |
| 凸显 | 突显（二者近义，统一用"凸显"） |

### 高频虚词错误

- **的 / 地 / 得**：定语用"的"，状语用"地"，补语用"得"（"做得好""认真地做""我的文件"）。
- **在 / 再**："在"表位置或进行（在会上），"再"表重复（再次）。
- **即 / 既**："即"是就是、立刻（即为、立即）；"既"是已经（既然、既……又）。
- **做 / 作**：具体动作多用"做"（做工作），抽象或固定搭配用"作"（作为、作出决定）。
- **其他 / 其它**：指事物时统一用**其他**。
- **帐 / 账**：与钱财有关一律用**账**（账目、台账、账户）。

### 数字、单位与标点

- 年份写全四位；同一材料内数字用法一致（要么全用阿拉伯数字，要么全用中文数字，不混用）。
- 百分比、金额、序号用阿拉伯数字；概数、成语、固定词组用中文数字（"三个方面""十四五"）。
- 数值区间用"～"或"—"连接，不写"~"。
- 单位符号规范：平方米写"平方米"或"m²"，不写"平米""平方"；"kW·h"不写"度"（正式材料）。
- 标点：全文统一全角中文标点；括号、引号成套；书名号《》与尖括号<>交替用于多层书名；顿号只用于并列词语之间。
- 句末标点不重复（不用"？！"叠加），标题末尾一般不加点。

## 二、用词优化（删、换、实）

1. **删冗余**："进行了""开展了""作出……的部署"→ 直接用动词（"开展检查"优于"进行了检查的开展"）；删"各种""相关""一定的""进一步"等无信息量修饰。
2. **换口语**：搞定→完成、落实；弄好→做好；差不多→基本一致；大概→约。
3. **去套话**：删除"赋能、抓手、闭环、打法、生态位"等公文不适用的流行词（详见 `wording-rules.md` 禁用表）。
4. **去 AI 腔**：删"值得注意的是""综上所述""首先其次最后"等机械连接词；删项目符号卡片式罗列。
5. **评价落地**：凡是"显著""大幅""全面"这类评价词，后面必须跟具体对象、数据或事实；没有依据就改成平实表述。
6. **重复词**：同一段内不重复同一动词；相邻句不重复同一开头方式。

## 三、句式优化

1. **长句拆分**：单句超过约 60 字且含多层定语时，拆成两句，或把长定语提前为分句。
2. **主谓完整**：避免"通过……使……"这类缺主语句（去掉"通过"或去掉"使"）。
3. **动宾搭配**：检查"提高……建设""加强……水平"这类错误搭配（应为"加强建设""提高水平"）。
4. **并列对称**：并列的几项结构一致（都是动宾或都是名词短语），长短相近。
5. **结论前置**：段落第一句给出结论或判断，后面再摆事实；不要铺垫到最后才说重点。
6. **一段一意**：一个自然段只讲一个意思；转换话题另起一段。

## 四、不改动的部分（边界）

- 不改动**事实、数据、时间、金额、人名、地名、机构名称、专业术语、政策原文引用**。
- 不改动用户刻意坚持的表达习惯（若用户明确要求保留）。
- 不擅自补充材料里没有的内容；有疑点列为待确认，不猜。
- 方言、口语在**发言稿**中可能是有意的（更自然），仅在过于随意时才建议调整，并说明理由。

## 五、输出方式

- 改动按**两级**标注：**必改**（错别字、病句、硬伤）与**建议**（风格优化，可保留）。
- 用清单形式列出：

| 位置 | 原文 | 改为 | 类型 | 理由 |
| --- | --- | --- | --- | --- |
| 第 2 段 | 布署工作 | 部署工作 | 必改 | 错别字 |
| 第 4 段 | 进行了检查 | 开展检查 | 建议 | 冗余 |

- 用户要求"直接改好"时：正文直接输出改后版本，改动清单附在末尾供核对，不要只给建议不改稿。
