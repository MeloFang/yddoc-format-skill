# 公司文种口径

> 依据：《附件1：发文基本规范说明》"一、文件标题"与"四、文件结尾"。
> 公司明文给出的文种只有**通知、报告、批复、请示**四种；其余文种（函、纪要等）公司暂无特别规定，按 `chinese-official-writing` 通用规则处理。

## 一、文种与结尾语（一一对应，不得串用）

| 文种 | 结尾语 | 备注 |
| --- | --- | --- |
| 通知 | **特此通知。** | 下行文 |
| 报告 | **特此报告。** | 上行文，不得夹带请示事项 |
| 批复 | **特此批复。** | 下行文 |
| 请示 | **以上妥否，请批示。** | 上行文，一文一事，事前行文 |

结尾语与正文之间**不留空行**。

> **请示不特殊化**：请示与普通公文版式完全一致，区别只有三处——红头不同（**由公司系统自动生成，本技能不处理**）、结尾语用"以上妥否，请批示。"、需显示签发人并在文末加联系人（`（XX分公司联系人：张三139XXXXXXXX）`）。除此之外按普通公文处理，不要额外叠加规则。

## 二、标题构成规则（原文硬要求）

公式：**发文单位 + 关于 + 某事 + 文种**

- **下行文**：发文单位**可以省略**。
- **上行文**：发文单位**不能省略**。
- 结尾统一用"**的** + 文种（两字）"，如"……的**通知**""……的**请示**"。

### 结构示例（占位符仿写，真实单位名不入库）

| 行文方向 | 示例结构 |
| --- | --- |
| 下行文·批复 | 关于`<XX分公司>`……的批复 |
| 上行文·请示 | `<XX分公司>`关于……的请示 |
| 上行文·请示/报告 | `<本部>`关于……的请示 / `<本部>`关于……的报告 |
| 上行文·党委文件 | `<本部>党委`关于……的请示 / `<本部>党委`关于……的报告 |

> 尖括号内占位符需向用户索取实际单位名称后替换，不要自行补全。

## 三、通用范文骨架（脱敏结构）

完整版式基底见 `assets/发文模板-通知.docx`（正文已脱敏）。通知类文件的通用结构如下，起草时照此骨架展开：

```
标题：关于XXXXXX的通知
主送：　各分公司：
引言：为深入推进……，严厉整治……，严格落实……《……》，（目的 + 依据）
一、从严规范<业务环节A>审批管理
二、坚持开展<业务环节A>风险评估
三、严控<环节B>操作风险
四、强化重点高风险场景管控与惩戒
    （一）严格<违规情形一>管控
    （二）加大<违规情形二>惩戒力度
    （三）强化<违规情形三>处置
    （四）从严惩处<特定对象>违规营销
    （五）严格<业务动作>核验标准
        1.情形描述一；
        2.情形描述二；
        ……
五、严肃管理人员追责问责
    （一）追责触发条件
    （二）追责适用情形
    （三）追责实施要求
六、健全闭环管理机制，严格执行自查自纠
结尾语：特此通知。（独占一段，前不空行）
```

### 从范文提炼的写法要点

- **主送**：下行文通知统一用"各分公司："（顶格，全角冒号）。
- **一级标题用动宾结构**：从严规范、坚持开展、严控、强化、严肃、健全——起首即表明态度。
- **引言三段式**：目的（为……）＋问题（整治……违规）＋依据（严格落实XXX公司《……》）。
- **列举用编号不用段落**：违规情形、追责条件这类并列项用"1. 2. 3."逐条列出，每条一个独立判断，句末用分号或句号。
- **处罚标准写明金额或量化口径**，如"按不低于 X 元/笔标准扣罚"——具体数值由用户给定，不预置。
- **结尾语独占一段**，与正文之间不留空行。

## 四、行文方向铁律

- 上行文不替上级做决定；下行文要有可执行要求；平行文保持商洽语气。
- 上行文的发文单位（含"党委"字样时须带全衔）**不得省略**。
- 请示用于请求批准、报告用于汇报情况，二者不得混用，不得在报告中夹带请示事项。
- **部门通知不要发省公司**——部门通知只适合下行文。
- **省公司批复部门通知、邮件等都可以**（批复载体灵活）。
- **请示必须显示签发人**，且文末加联系人，格式：`（XX分公司联系人：张三139XXXXXXXX）`。
- **联合发文一定要老总签发**。

## 五、认定顺序

不确定文种时，先按 `chinese-official-writing` 技能的文种路由判定通用口径，再用本表校正为公司口径。两者冲突时以本表为准。
