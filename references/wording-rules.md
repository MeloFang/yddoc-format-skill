# 用词与称谓规范

> 依据：《附件1：发文基本规范说明》。公司文件给出的用词类要求集中在"禁止项"和"序数用法"上；标注"公司未规定"的部分按通用公文口径处理。

## 一、硬性禁止项（来自规范原文，优先级最高）

| 禁止项 | 说明 |
| --- | --- |
| 正文加粗 | 公司明文规定正文字体不加粗；层级靠序数和字体区分，不靠加粗 |
| 正文中的空格 | 正文不得出现空格（含段内、标点前后的多余空格） |
| 正文中的空行 | 段落之间不得留空行，**结尾语与正文之间也不留空行** |
| 自动编号 | 层次序数不得用 Word 自动编号，必须手写成文本 |

## 二、层次序数用法

严格按 `一、` → `（一）` → `1.` → `（1）` 四级递进，不得跳级、不得混用（如第二层直接用"1."）。

- 序数后不加标点的情况：一级"一、"本身带顿号；二级"（一）"不加标点；三级"1."用下圆点。
- 一级用黑体、二级用楷体、三四级用仿宋_GB2312（见 `format-rules.md`）。

## 三、机构称谓

公司为**本部 + 下属分支**的两级结构：本部发文，下辖若干分支单位；涉及党委的文件另有专门称谓。

| 角色 | 写法 |
| --- | --- |
| 本部（上行文发文单位） | `<本部全称>`，党委文件时用 `<本部全称>党委` |
| 下属分支（下行文对象 / 上行文发文单位） | `<XX分公司>` |

- **具象单位名不入库**：本技能不保存任何真实机构名称、上级集团名或所属区域，**一律向用户索取**，或用 `<本部全称>` / `<XX分公司>` 占位。
- 对外文件用全称，行文正文可用简称，**首次出现须写全称**。
- 党委行文须在单位名称后加"党委"二字，如"`<本部全称>党委`关于……的请示"。
- 正式称谓以用户提供的单位全称为准；不确定时用全称，不擅自简化。

## 四、禁用 / 替换词表（通用公文口径，公司未另作规定）

| 禁用词 | 替换为 | 原因 |
| --- | --- | --- |
| 赋能、抓手、闭环、打法 | 直接删除该表述 | 公文口径不用 |
| 搞好、弄好、搞定 | 做好、完成、落实 | 口语化 |
| 大概、差不多、可能吧 | 直接删除或改为明确表述 | 公文不得含糊 |
| 进一步优化 / 不断加强 / 显著提升 | 落到具体对象、动作、时限或数据 | 无实质内容支撑 |

## 五、语气纪律

- 正式的第三人称书面语，**单位视角**，不用"我""我们建议大家"。
- 除新闻评论类任务外，不使用旁观者、教师或评论员口吻。
- 评价性词语必须落到对象、动作、责任、时限、数据或制度载体；没有依据就改成材料能支持的平实表述。
- 每段只服务一个论点，一般按"结论前置 → 事实支撑 → 判断归纳 → 事项落点"展开。

## 六、惯用句式

- 开头依据：根据《XXX》（`<代字>〔YYYY〕N号`）要求，结合公司实际，
- 措施承接：现将有关事项通知如下：
- 责任与时限：由 XX 部门牵头，于 X 月 X 日前完成。
- 反馈要求：请各单位将落实情况于 X 月 X 日前报送 XX。
- 请示联系人（文末）：（XX分公司联系人：张三139XXXXXXXX）

## 七、引用与数字书写（明文规定）

- **年份必须写全四位**：写"2018年"，不得简写"18年"。
- **引用文件必须带文号**，标准格式：`《标题》（<代字>〔YYYY〕N号）`——书名号夹标题，文号用六角括号紧跟其后；**文号须从原文件复制**。
- 文号年份外的括号是**有弧度的六角括号〔〕**，须**从原文件复制**，不得凭记忆手打。
- **多个书名号交替使用**：先《》后<>，如《A<B>》。
