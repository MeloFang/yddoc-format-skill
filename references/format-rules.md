# 公司版式规范

> 依据一：《附件1：发文基本规范说明》+《发文规范补充》（公司规范原文两部分）——明文条款，最高优先级。
> 依据二：公司实际发文模板 `assets/发文模板-通知.docx`——实测版式参数（模板正文已脱敏，只保留版式与结构）。
> 依据三：用户补充的页面设置（页边距、奇偶页不同、页眉页脚、西文字体、文档网格）与落款规则。
>
> **适用范围**：本文件的页面、字体、行距、层级序数、落款规则对**公文与普通文章一视同仁**；只有发文字号、主送、文种结尾语是公文专属。
> **脱敏说明**：本文只记录格式规则，不保存任何真实单位名、代字、文号或业务标题；示例中一律使用占位符。

## 一、正文字体与排版（明文规定 + 模板实测一致）

| 项 | 规定值 |
| --- | --- |
| 正文字体（中文） | 仿宋_GB2312 |
| 正文字体（西文） | **Times New Roman** |
| 正文字号 | 小四（12 pt） |
| 行距 | **1.5 倍行距**（2026-09-09 用户明确修正：不再用固定值 28 磅） |
| 首行缩进 | 2 个字符（实测 31 pt） |
| 对齐方式 | 两端对齐 |
| 正文加粗 | **禁止** |
| 正文中空格、空行 | **禁止**（唯一例外见"附件排版"） |
| 结尾语与正文之间 | **无空行** |

## 二、标题与主送（模板实测）

| 位置 | 字体 | 字号 |
| --- | --- | --- |
| 文件标题 | **方正小标宋简体** | 三号（16 pt） |
| 主送机关（如"各分公司："） | 仿宋_GB2312 | 小四（12 pt） |

- 标题居中排列。
- 主送**顶格**写，结尾用全角冒号"："（原模板主送前误带全角空格，修正版已去除）。
- 下行文标题可省略发文单位（形如"关于XXXXXX的通知"）。

## 三、结构层次序数（明文规定）

序数依次为 **"一、" → "（一）" → "1." → "（1）"**，**不得套用 Word 自动编号**；每个自然段开头空 2 个字格。

| 层级 | 序数形式 | 字体 |
| --- | --- | --- |
| 第一层 | 一、 | **黑体** |
| 第二层 | （一） | **楷体**（仅限标题性短句） |
| 第三层 | 1. | 仿宋_GB2312 |
| 第四层 | （1） | 仿宋_GB2312 |

> **序数段 ≠ 自动是标题**：判断标准是**内容性质**，不是有没有序数。序数后接短语式标题（如"（一）追责触发条件"）→ 按层级字体（楷体）；序数后直接展开完整叙述句或机制说明（如"（一）以上扣罚标准适用于……"整段论述）→ 该段属**正文**，用仿宋_GB2312，不得因带序数就套楷体。

> **模板已修正**：原始模板一、二级标题实为正文仿宋，与规范不符。2026-09-08 已生成修正版替换 `assets/发文模板-通知.docx`（一级黑体、二级楷体_GB2312）。

## 四、页面设置（用户给定，公文与普通文章统一适用）

| 项 | 规定值 |
| --- | --- |
| 纸张 | A4（595.3 × 841.9 pt） |
| 上边距 | **3.7 cm** |
| 下边距 | **3.5 cm** |
| 左边距 | **2.8 cm** |
| 右边距 | **2.6 cm** |
| 页眉 | **1.5 cm** |
| 页脚 | **2.6 cm** |
| 版式 | **勾选「奇偶页不同」** |
| 文档网格 | **每行 28 字、每页 22 行** |
| 西文字体 | **Times New Roman** |
| 页面方向 | 纵向 |

> 模板实测页边距与规定一致（37/35/28/26 mm），但页脚距离为 25 mm（2.5 cm），与规定的 2.6 cm 相差 1 mm；严格按规范时需微调。

## 五、发文字号规则（两级代字）

公司存在**两级发文主体**，代字结构不同，落笔前须确认本次是哪一级：

| 层级 | 代字结构 | 说明 |
| --- | --- | --- |
| 公司级发文 | `<公司代字><部门代字><文种代字>` | 由多个代字段拼接而成 |
| 部门级发文 | `<部门代字><文种代字>` | 部门代字 + 文种代字，如"XX部"+"通" |

- 格式：**代字 + 〔年份〕+ 序号 + "号"**，抽象形式为 `<代字>〔YYYY〕N号`。
- **具体代字不入库**：本技能不记录任何真实代字，使用时向用户索取或让其从原文件复制。
- 年份用六角括号 **〔〕**，不用方括号；序号**不编虚位**（写 106，不写 0106）。
- **年份必须写全四位**，不得简写（"18年"这类写法违规）。
- 引用其他文件时**必须附上文号**，且**从原文件复制**，不得凭记忆手打。
- 代字不确定时**不编造，须向用户确认**。

## 六、文件命名规则

- 有字号：**发文字号 + 标题**，如 `<代字>〔YYYY〕N号关于XXXXXX的通知`。
- 无字号（下行批复等）：**单位 + 关于 + 事由 + 文种**，如 `XX分公司关于XXXXXX的批复`。
- 多附件交付时，附件文件按 `1. 2. 3.` 序号前缀命名。
- 同一发文通常同时产出 `.docx`、`.pdf`、`.html` 三种形态。

## 七、附件排版（明文规定）

- **正文与附件之间空一行**——这是全文唯一允许空行的位置（结尾语与正文之间仍不空行）。
- 附件说明置于**结尾语之后**：

单附件：

```
特此通知。

附件：XXXX年度经营绩效考核指标分解表
```

多附件（序号列举，第二行起与首个附件名对齐）：

```
特此通知。

附件：1. XXXX年X月XXXXXX考核表
      2. XXXX年X月XXXXXX统计表
```

## 八、落款、签发与联系人（明文规定）

- **落款位置：正文下空 3 行**；**日期文本后缩进 4 字符**。
- **请示必须显示签发人**（规范原文黄色高亮强调）。
- **请示类文件末尾加联系人**，格式：`（XX分公司联系人：张三139XXXXXXXX）`。
- **联合发文一定要老总签发**。
- 列举内容排版**上下对齐，每行各空两格**。
- 模板中无署名、成文日期、印章——用户未要求时不主动补；要求时必须先确认，不得编造。
- **红头由公司系统自动生成，本技能不生成、不校验红头，也不需要红头模板。**

## 九、表格与图片排版（汇报材料 / 发言稿适用）

> 公司规范只约束公文，未规定图表。以下为**用户明确要求 + 通用排版做法**，与公文规范冲突时按本节执行。

### 9.1 表格

| 项 | 规定 |
| --- | --- |
| 表内文字字体 | **微软雅黑**（表头、正文单元格一律） |
| 表内字号 | **五号（10.5 pt）**；表格内容极少时可同正文小四 |
| 表头 | 微软雅黑**加粗**（表格非正文，不受"正文不加粗"约束） |
| 表内行距 | **单倍行距或固定值 18–20 磅**（此处**突破**正文 1.5 倍行距限制，表格照旧） |
| 表格宽度 | 不超过版心宽度 **15.6 cm**（A4 减去左右边距）；内容少时按内容收缩后居中 |
| 表格位置 | **页面居中** |
| 单元格对齐 | 表头居中；文字左对齐或居中；**数字右对齐** |
| 表题 | 表格**上方**居中，微软雅黑小四 |
| 表格与正文间距 | 上下**各空一行**（此处**突破**正文禁止空行限制） |

- **小表不跨页**：表格高度不超过版心 1/3 时，禁止跨页断裂；临近页尾则整体下移或微调上文。
- **大表才跨页**：一页放不下的大表允许跨页，但**必须重复标题行**，且尽量避免标题行后立刻断页。

### 9.2 图片

| 项 | 规定 |
| --- | --- |
| 位置 | **页面居中** |
| 尺寸 | 按原始比例缩放，**宽度不超过版心 15.6 cm**；小图不必拉伸放大，保持清晰即可 |
| 跨页 | **一律不跨页**；单页放不下则整体缩小至页内 |
| 图题 | 图片**下方**居中，微软雅黑小四 |
| 与正文间距 | 上下**各空一行** |

### 9.3 可突破与不可突破

**可以突破**（为图表让位的合理例外）：正文中禁止空行、行距 1.5 倍、每页 22 行网格、表内字号。

**不可突破**：页面设置（A4 与页边距）、页眉页脚、奇偶页不同、**正文**字体字号行距、标题字体、层次序数、落款。

## 十、公司特有红线

1. 正文不能加粗、不能出现空格和空行（附件说明前空一行、图表与正文之间空一行是两处例外）。
2. 层次序数不得套用自动编号。
3. 结尾语与正文之间不留空行。
4. 标题结构 = 发文单位 + 关于 + 某事 + 文种；上行文不得省略发文单位（详见 `genre.md`）。
5. 年份写全四位；引用文件必须附文号并从原件复制。
6. 请示必须显示签发人、文末附联系人；联合发文必须老总签发。
7. 发文字号、落款等未提供的要素，不得编造；**红头由系统生成，本技能不处理**。
8. **请示版式与普通公文完全一致**，仅在结尾语、签发人、联系人三点上有别，不得额外叠加格式规则。
9. 本文件的页面设置、字体、行距、层级、落款规则**对普通文章同样适用**，不是公文专属。
10. 图表排版按第九节执行——表内微软雅黑、整体居中、**小表小图不跨页**，大表跨页须重复表头；为给图表让位可突破空行、行距、网格、表内字号四项限制。
